# Vocabulary Usage Rules

## Language Policy

1. Write documentation in Traditional Chinese.
2. Keep proper nouns and source-level identifiers in English.
3. Do not translate API names, class names, struct names, enum names, function names, namespaces, macros, file names, directory names, commands, tools, libraries, or framework names.
4. Do not mix Simplified Chinese into documentation.
5. Use neutral, objective, and technical wording.
